موقع إبراهيم النجار الشخصي
========================

محتويات الملف:
- index.html : الصفحة الرئيسية للموقع
- style.css  : التصميم المتجاوب للموبايل والحاسوب

طريقة التشغيل:
1. فك ضغط الملف ZIP.
2. افتح المجلد.
3. افتح index.html في المتصفح لمعاينة الموقع.

النشر على الإنترنت:
يمكن رفع الملفات على GitHub Pages أو Netlify أو أي استضافة مواقع ثابتة.
الموقع يستخدم خط Cairo من Google Fonts، لذلك قد يظهر بخط بديل إذا لم يتوفر اتصال بالإنترنت.

ملاحظات:
- روابط Atlas AI وLewiseshop قابلة للتعديل داخل index.html.
- عدّل النصوص إذا أردت إضافة رقم الهاتف أو روابط حساباتك الاجتماعية.
